THE LAST DANCE — BIRTHDAY WEBSITE
================================

1. Open the birthday-legend folder in VS Code.
2. Add your pictures to the assets folder using these exact filenames:
   - deathnote-light.jpg
   - deathnote-ryuk.jpg
   - itsuki.png
   - anime-romance.jpg
   - basketball.jpg
   - volleyball.jpg
3. Open index.html in your browser to test the website.
4. All navigation buttons link to separate HTML pages.
5. To publish: upload every file and the assets folder to a GitHub repository.
   Then go to Settings > Pages > Deploy from a branch > main > /(root) > Save.

IMAGE NOTE:
The image files are not bundled because you should choose the pictures you want
to use. Use images you have permission to publish. The HTML already contains
the image locations and filenames.

CUSTOMIZE:
- Edit the friend's name and jokes in letter.html.
- Edit the final message in surprise.html.
- Edit the access code and pass text in snooker.html.
